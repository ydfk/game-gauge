# 存档备份

在游戏仪表打开「存档备份」。功能在普通权限的 `GameGauge.Saves.exe` 中运行，关掉设置窗口后仍可使用。自动备份初始暂停，配置时可单独开启。监控条、采集和 OBS 均有各自的开关。

## 配置 Steam 游戏

1. 对《影之刃零》，点「选择 Steam 账号」，或在「编辑备份规则」中手动选择含 `PBZSaveGame.sav` 的 17 位账号目录。识别到的目录来自 Steam 库。
2. 对其它游戏，点「添加 Steam 游戏」，填写已安装游戏的 Steam App ID、实际进程文件名和该游戏专用的存档目录。这个目录中的普通文件和子目录会进入备份。
3. 启用自动备份后，运行中按设定间隔检查，检测到退出后再检查一次。存档内容没变会跳过。保留数量针对未保护的自动备份。WebDAV 已配置时，尚未收到完整上传回执的自动备份暂缓清理。
4. 在「备份库」对所选档案点「立即备份」。托盘和默认快捷键 `Ctrl+Alt+F8` 优先选择唯一正在运行的已配置游戏。多款运行时打开设置，请选游戏后手动触发。没有运行中的游戏时使用当前选择。

全局备份快捷键可在「编辑备份规则」改成 Ctrl 或 Alt 加字母、数字或功能键的组合，留空停用。原版留档也可能已注册 `Ctrl+Alt+F8`。

## 从留档 0.2.0 迁移

1. 在「游戏与规则」点「预览旧库」。读取当前用户的 `%LOCALAPPDATA%\SaveKeep\settings.json`、默认备份根及已登记的自定义根。确认来源、档案、预计复制字节和冲突数量。
2. 退出旧留档后确认复制。每条记录单独暂存，验证 UUID、大小、SHA-256 和 ZIP 内容后提交。重复记录可跳过，冲突保留在各自的库中。出现失败时保留源目录，处理错误后可以重新预览并继续。
3. 普通数据目录是 `%LOCALAPPDATA%\GameGauge\saves`。默认备份位于其 `Backups\SaveKeep Library\<game>\<profile>\<uuid>\`。现有已配置游戏的自定义目标可能接收迁入的备份。同游戏的其它 Steam 账号备份会一同复制，切换到对应账号后查看。
4. 如果旧留档有 WebDAV 设置，游戏仪表可复制地址和用户名，新配置的自动上传初始暂停。请在「云端」通过 Windows 凭据对话框重新输入密码并测试连接，再决定是否启用自动上传。

## WebDAV

使用已存在的 HTTPS 目录，填入用户名，保存后点「输入密码」和「测试连接」。选中本地备份可手动上传。使用「浏览远端」查看当前游戏的清单，选中对应档案后校验并下载到本地库。下载后从「备份库」恢复。

远端沿用 `SaveKeep/<game>/<profile>/<uuid>.zip` 和同名 `.json`。ZIP 提交后发布清单，失败会重试。删除本地记录和保留规则均保留远端副本。

## 恢复与回退

先退出游戏并等待 Steam Cloud 同步完成。选中备份后可先单独校验。恢复会验证压缩包，在有效存档存在时创建一份受保护的备份，并在存档同盘暂存后替换。成功后保留同级的 `.savekeep-preserved-*` 原目录，界面会给出路径。

如果恢复被中断且出现 `.savekeep-original-<原目录名>`，先关闭游戏和同步，确认当前目录状态。原目录缺失时，可把上述文件夹改回原来的完整目录名。若新旧目录同时存在，先将两个目录另行备份，再决定使用哪份。恢复后从游戏内确认进度，再处理 Steam Cloud。

可暂停游戏仪表的自动备份并退出程序，重新启动留档使用旧库。两种程序都使用 v1 的 `record.json` 和 `save.zip`。如需带回新备份，先在游戏仪表校验，再退出两个程序，把完整 UUID 目录复制到旧备份根下相同的游戏和档案目录，避免覆盖已有 UUID。覆盖升级与卸载均保留用户数据和备份目录。
