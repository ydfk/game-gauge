# SaveKeep 0.2.0 迁移验收

## 基线与本地包

GameGauge 通过 GitHub HTTPS 快进拉取。拉取后的远端 `main` 与本地 HEAD 同为 `c4abfe7f0251f6dfa8e032880986eb878289a20f`，原源码 `VERSION` 为 `0.1.24`。本地预览包使用构建参数 `0.1.25`，输出到 `build/package/saves-local/`。

工作进程使用 Rust 1.97.1 MSVC 和静态 CRT。检查 PE 依赖只见 Windows 系统 DLL，未见独立的 VC Runtime DLL。安装包 PE 资源和便携 ZIP 中的宿主、设置与工作进程版本一致，包内清单记录的 SHA-256 校验通过。锁定依赖的许可证和索引随包交付。

## 功能和回归

- Release 构建和 CTest 共 3 组通过，包括 16 项 Rust 单测。Cargo `--locked`、Clippy 和格式检查通过。
- 用 GameGauge 生成合成备份，使用原版 SaveKeep 0.2.0 核心读取、校验并恢复。反向使用旧核心生成 v1，GameGauge 预览、复制和校验通过，源 ZIP 的 SHA-256 保持一致。另覆盖默认与自定义根、部分迁移失败续跑、同 UUID 异哈希和拒绝 NTFS junction。
- 宿主测试覆盖重复投递、跨重启查询、中文元数据、保护恢复、分页、工作进程异常重启和组件缺失。备份期间原监控 IPC 仍可用。恢复目录替换失败时，合成原目录可以自动回滚。对 384 MiB 合成档案，在恢复期间请求退出，IPC 保持可用，校验、恢复和保留原目录完成后，宿主与工作进程退出。
- 原生设置页完成备份规则对话框的实际打开和取消。以 125%、150% 和 200% DPI 参数离屏渲染三个备份页签，沿用现有设置窗口缩放上限。窗口生命周期、HUD 显隐及层级、OBS 回环认证与录制状态回归通过。
- WebDAV 回环覆盖清单发布失败、重启重试、上传回执、云端下载与恢复。凭据通过 Windows 凭据管理器读写，迁移和诊断接口传递公开设置及凭据标识。
- 旧版安装包解出后，在隔离目录启动、关闭、覆盖升级并重启。新版工作进程随宿主退出，测试历史和备份文件原样保留。安装器 UI 预览、文件锁测试、发布脚本模拟和 Actionlint 通过。

## 本机性能样本

用同一个 DX11 测试进程和 PresentMon 共享服务测量，工况中包含 384 MiB 合成存档。一次对照的 P95 呈现间隔为自动备份关闭时 **6.600 ms**（920 帧），压缩期间 **6.588 ms**（1,448 帧）。压缩任务耗时约 **5.94 秒**，工作进程消耗约 **5.11 CPU 秒**。启动后空闲工作集约 **9.5–9.8 MiB**，备份结束采样为 **10.3 MiB**。备份期间的一次宿主诊断请求含进程启动耗时 **28.1 ms**。模拟游戏退出后检查到一份退出备份。

以上为本机短时合成样本。备份工作进程内顺序执行磁盘和 WebDAV 操作，长时间网络任务可能推迟后续本地任务。

## 实机验收边界

待验证的范围包括 Steam 实机游戏与物理快捷键、第二款真实 Steam 游戏、真实 Steam Cloud、真实 OBS 录制与成片、真实 NAS 的认证和权限、跨屏 DPI 切换、干净 Windows x64 的安装与卸载，以及真实游戏中的帧时间对照。安装、迁移和恢复测试均使用工作区内的合成数据和隔离目录。对外分发需要确认项目授权。
